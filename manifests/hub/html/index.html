Как это собрано

Стенд собран, чтобы разбираться, а не чтобы держать нагрузку: k3s на двух нодах, хранилище на Longhorn с репликами, секреты в git через Sealed Secrets, выкладка через Argo CD. Страницу правишь в одном файле — коммит, и Argo сам перезапускает под.

Метрики приходят из Prometheus, логи — в Loki, панели — в Grafana. Ничего из этого не обязано работать в три ночи, и это приятно.
